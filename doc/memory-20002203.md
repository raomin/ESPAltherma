# Hydro board software 20002203: what its RAM holds

Software 20002203 runs the 4-8 kW EHVH/EHVX/EHVZ/EHBH/EHBX E, EA and EJ series (Altherma 3 R), the 9-16 kW EBLA/EDLA monoblocs and the EWAA/EWYA chillers. Everything below was read on an **EHBX08EF6V** with an ERGA06EVH outdoor unit (November 2026), with the **Memory read** of the diagnostics page (command `R`, nothing written). Addresses are RAM addresses of the hydro board.

## Used by ESPAltherma

| Address | Type | What | How it was checked |
| ------- | ---- | ---- | ------------------ |
| `0x3470` / `0x34AE` | word, value × 256 | hot water curve, mild / cold point | equal to the interface's settings |
| `0x3472` / `0x34B0` | word, value × 256 | leaving water curve, mild / cold point (`[1-03]` / `[1-02]`) | 25 / 38 as set; a write changes the target at once |
| `0x2EE8` | word, value × 256 | the hot water target the thermostat aims for | equal to *DHW setpoint* |
| `0x2F3C` | word, value × 256 | the leaving water target the thermostat aims for, **shift included** | 37 written with a +10 K shift on the interface read 47 |
| `0x4E70` | byte | power limitation, `[4-08]`: 0 none, 1 continuous, 2 digital inputs | 2, as the unit's settings export says |
| `0x4E71` | byte | `[4-09]`, kind: 1 = kW | 1 |
| `0x3476` | float | `[5-09]`, limit 1 in kW | 20.0 |
| `0x4E50` | byte | `[5-05]`, limit 1 in A | 50 |
| `0x41A8` / `0x41AC` | float | active limit (kW / A) | |
| `0x08E6` | 32-bit count | **heat produced** since the installation, kWh (*Unit meter: Heat produced*) | rose by 15 kWh in 16 h of heating; the same count as a float at `0x3756` |
| `0x36B2` | 16-bit count | operating hours, space heating | 3240, as *Information > Operating hours* |
| `0x3696` | 16-bit count | operating hours, space cooling | 251, as the interface |
| `0x3650` | 16-bit count | operating hours, tank | 691, as the interface |
| `0x3692` | 16-bit count | operating hours, pump | 4552, as the interface |

The operating hours go to MQTT and Home Assistant as `Unit meter: Space heating hours (h)` and so on, next to the heat produced, read once a minute.
